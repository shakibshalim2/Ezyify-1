## 💳 Payment System

### Escrow Workflow

```
┌─────────────────────────────────────────────────────────┐
│ 1. Buyer Places Order                                   │
│    → Payment deducted from wallet                       │
├─────────────────────────────────────────────────────────┤
│ 2. Escrow Locks Funds                                   │
│    → Status: "locked"                                   │
│    → Auto-release: 7 days                               │
├─────────────────────────────────────────────────────────┤
│ 3. Seller Ships Product                                 │
│    → Status: "shipped"                                  │
│    → Tracking info added                                │
├─────────────────────────────────────────────────────────┤
│ 4. Buyer Confirms Delivery (BUYER ONLY!)                │
│    → Rate product condition                             │
│    → Upload photos                                      │
├─────────────────────────────────────────────────────────┤
│ 5. Escrow Releases Funds                                │
│    → Calculate commission (5-15%)                       │
│    → Seller receives: amount - commission               │
│    → Platform receives: commission                      │
├─────────────────────────────────────────────────────────┤
│ 6. Order Completed                                      │
│    → Status: "completed"                                │
│    → Funds distributed                                  │
└─────────────────────────────────────────────────────────┘
```

### Commission Rates

| Category | Rate |
|----------|------|
| Electronics | 10% |
| Fashion | 12% |
| Beauty & Personal Care | 15% |
| Home & Living | 8% |
| Sports & Outdoors | 10% |
| Books & Media | 7% |
| **Default** | **10%** |

### Key Rules

- ✅ **Wallet-only payments** (NO COD)
- ✅ **Buyer-only confirmation** (Sellers cannot confirm)
- ✅ **Auto-release after 7 days** (Cron job required)
- ✅ **Commission on every sale** (Platform revenue)
- ✅ **Escrow protection** (Buyer-seller trust)
