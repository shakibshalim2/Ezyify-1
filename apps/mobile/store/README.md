# Play Store listing assets

| Asset | File | Play requirement |
|---|---|---|
| App icon | `icon-512.png` | 512×512 PNG, ≤1 MB, no alpha needed |
| Feature graphic | `feature-graphic-1024x500.png` | 1024×500 JPG/PNG, no text near edges |
| Phone screenshots | `screenshots/phone/*.png` | 2–8 images, 16:9 or 9:16, min 320 px, max 3840 px — capture with `pnpm screenshots` (Phase 4.7) |
| 7" / 10" tablet screenshots | optional | required only when opting into tablet listing |

Content and policy declarations live in `docs/plan/PLAY_STORE_CHECKLIST.md`.
